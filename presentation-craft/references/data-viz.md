# Data visualization

A chart exists to make one pattern obvious. If the reader has to hunt for the point, the chart failed — even if it is accurate.

## Chart choice

| Relationship | Use | Avoid |
|---|---|---|
| Compare categories | bar (horizontal when labels are long) | pie with >3 segments |
| Change over time | line; columns for few periods | bars with many periods, area stacks with many series |
| Composition | stacked bar; pie only for 2–3 parts | donut with many slices |
| Variance / bridge | waterfall | stacked bars with negatives |
| Two variables | scatter | dual-axis line (misleading scales) |
| Ranking | sorted bar | unsorted bar |
| Exact values matter | table (≤ ~5 columns, ~8 rows on a slide) | 12-column tables |

## Checks

- **Takeaway is visible**: the chart's one point matches the slide title, and is emphasized (one highlighted bar/series, others in grey).
- **No 3D**, no shadows, no gradients on data marks — they distort comparison.
- **Direct labels over legends** where possible; a legend forces color matching.
- **Restrained color**: one accent for the focus, grey for context; semantic colors (green/red) used consistently. Rainbow series without reason is a finding.
- **Honest axes**: bar charts start at zero; truncated axes are disclosed; dual axes justified.
- **Units and sources**: units on axes or labels; source line for external data; date/period stated.
- **Numerical consistency**: numbers in charts match numbers in titles, text and other slides. A mismatch is **critical**.
- **Precision**: no false precision (34.27% when 34% suffices); consistent decimals.
- **Readability**: labels legible at presentation size; no overlapping labels; no gridline clutter.
- **Tables**: aligned numbers (right-aligned, same decimals), highlighted key row/column, no full gridlines.

## Score anchors

5 — every chart makes one point instantly, honestly and legibly
4 — minor issues (a legend, a missing unit)
3 — wrong chart types or unhighlighted takeaways in several places
2 — charts obscure the message or are hard to read
1 — misleading or contradictory data
